# Arkitect v1.0.44

## Install

Download and run the Setup `ArkitectSetup-vX.Y.Z.exe` below.  
Requires Windows 10/11 and ARK: Survival Evolved (Steam).

## Activating Pro

After Ko-fi purchase your key is emailed automatically.  
Open Arkitect -> Discord -> Login -> License -> paste key -> Activate. No restart needed.
