# Arkitect v1.0.29

## What's new

**New Pro features**
- **Fed-Suit** `F5 / F6` fully automates transmitter slot-transfers for the Federation Suit grind; configurable interaction key, delays, and transfer count
- **Custom Graphics** six reversible one-click visual tweaks: disable water surface, glitched Tek-Suit, glitched Flak, glitched C4, glitched Tek-Rifle; Arkitect keeps verified backups and can restore everything instantly
- **Custom Crosshair** overlay a custom crosshair in any color, size, gap, and style while playing; toggle via hotkey
- **Stretched Res** configure and apply a stretched resolution (NVIDIA GPUs only)
- **Caves** built-in cave browser with animation previews and per-cave helpers
- **INI Builder** build and export custom `Game.ini` / `GameUserSettings.ini` configs with a visual editor


**Fixes**
- Restart button now works correctly when running as a frozen EXE
- Update check is skipped when running in dev (unfrozen) mode
- Fixed a CTkToplevel crash on startup in frozen builds

## Install

Download `Arkitect.exe` or `ArkitectSetup-vX.Y.Z.exe` below.  
Requires Windows 10/11 and ARK: Survival Evolved (Steam).

## Activating Pro

After Ko-fi purchase your key is emailed automatically.  
Open Arkitect -> Settings -> License -> paste key -> Activate. No restart needed.
